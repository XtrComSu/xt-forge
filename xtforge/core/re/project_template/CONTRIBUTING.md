# Contributing

Open an issue with a question or an observation. Put confirmed findings in the [report](docs/REPORT.md) and give each finding a stable ID.

- Identify the artifact by version and SHA-256. If it came from an archive, record the member and architecture.
- Record the XT-Forge version, command and relevant output. Include the address space when citing an address.
- Share redistributable fixtures or sanitized excerpts. Keep private captures and original artifacts under `samples/` or `work/`.
- Update `docs/assets/showcase.gif` and its README alt text if your change alters the walkthrough.
- Refresh the commit activity chart from the branch you want to show with `python scripts/update_activity.py`.
