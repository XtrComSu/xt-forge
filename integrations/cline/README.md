# xt-forge for Cline / Roo Code

Cline and Roo Code read MCP server definitions from `cline_mcp_settings.json`.

## Quick Setup

1. Run `npx --yes github:XtrComSu/xt-forge init` (or `./install.sh`).
2. Merge [`cline_mcp_settings.json`](cline_mcp_settings.json) into your Cline / Roo Code MCP settings file.
