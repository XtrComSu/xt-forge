# xt-forge for Gemini CLI & Antigravity CLI

Gemini CLI / Antigravity CLI (`~/.gemini`) supports stdio MCP servers in `settings.json` and `XTF-*` skills in `~/.agents/skills/` and `~/.gemini/skills/`.

## Quick Setup

1. Run `npx --yes github:XtrComSu/xt-forge init` (or `./install.sh`) to install `xt-forge` on `PATH` and sync `XTF-*` skills.
2. Merge [`settings.json`](settings.json) into `~/.gemini/settings.json`.
