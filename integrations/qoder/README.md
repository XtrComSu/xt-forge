# xt-forge for Qoder CLI

Qoder (`~/.qoder`) supports stdio MCP servers (`xt-forge --meta`, `ghidra`, `ida`) and `XTF-*` agent skills.

## Quick Setup

1. Run `npx --yes github:XtrComSu/xt-forge init` (or `./install.sh`) to install `xt-forge` on `PATH` and sync `XTF-*` skills.
2. Merge [`mcp.json`](mcp.json) into your Qoder MCP configuration (`~/.qoder/mcp.json`).
